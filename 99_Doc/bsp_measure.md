# ADC采样与换算

更新时间：2026-11-02，按当前源码整理；名义公式不代表已标定。

## 采样链路

- TMR15 CH1每500 us硬件触发，非连续六路扫描；ADC各路239.5周期采样。
- 顺序：OUT_CUR/PA0、IN_CUR/PA1、BAT_VOL/PA4、VIN_VOL/PA5、NTC/PA6、
  VREFINT/内部CH17。六路先后采样，不是同时采样。
- DMA循环缓冲12个uint16_t，每半区一轮六路；BSP持有缓冲和原始快照。
- DMA中断分发后，BSP复制原值并发布序号；主循环换算、滤波和交付。
  特例：12 V BAT_VOL原值>=1760时，中断直接关PWM，无完整业务恢复互锁。
- 主循环只消费最新帧，不是完整队列。半满/全满积压丢弃该批并报告overrun；
  传输错误停止DMA。不能仅凭保留的旧测量数值判定采样有效。
- 电压和两路电流各自8帧滑动平均；NTC用ADC比值换算。采样持续性、滤波
  历史和错误状态须一同判断。256连续有效帧后上层ready。
- 功率启停不停止ADC；采样与100 kHz功率PWM没有固定同步相位。

## 电流含义与名义换算

| 项目 | 名义公式或含义 |
| --- | --- |
| VDDA[mV] | 1200×4096/VREFINT_raw |
| ADC引脚[mV] | raw×VDDA/4096，整数舍入 |
| 电池电压[mV] | ADC引脚mV×11 |
| 输入电压[mV] | 非零ADC引脚mV×20+1300；近零/截止不适用线性模型 |
| 两路电流[mA] | 对应ADC引脚mV×4 |
| NTC | 100 kΩ上拉、10 kΩ@25℃、B3950，输出0.1℃ |

IN_CUR/R6是Buck总输出，OUT_CUR/R8是外接负载；电池净电流=总输出-负载。
没有PV输入电流采样；INA180单向测量不能可靠识别反向电感电流。
标定参数位于00_Project_Config/board_measure_config.h，ADC原值0～4095，
换算分母4096；VREFINT使用典型值，电压/电流增益、零点和NTC仍待实物校准。
VIN模拟支路模型和首轮独立测量见adc_input_voltage_formula.md。

## 接口和初始化约束

- plat_adc只交付原始数据和DMA事件；缓冲静态分配、半字对齐，长度必须等于
  两倍扫描长度。回调指针是有覆盖期限的DMA视图，不得无限期保留。
- ADC/DMA初始化后、触发定时器启动前绑定测量回调；装配入口为
  app_startup_before_sampling，放在生成器原生user code区。
- ADC start/stop由启动/主循环上下文串行调用，禁止在ISR中执行；停止采样前
  先停触发。关闭功率输出使用独立PWM接口。
- BSP数据/错误回调在process中同步通知上层；保留数据时复制结构体。
  Watch跨字段读取不是原子快照，故障后实时值不代表故障触发帧。
- ADC校准的硬件等待超时仍需后续核对；本次文档整理未修改初始化代码。
