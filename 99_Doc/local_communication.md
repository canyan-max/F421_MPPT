## 1. 本机通讯格式

- 物理接口：RS485。
- 软件协议：Modbus RTU，当前功能码范围仅限 `0x03`（读保持寄存器）和
  `0x06`（写单个寄存器）；其他功能码暂不实现。
- 波特率：9600 bit/s。
- 从站地址：21（十六进制 `0x15`）。

### 1.2 通讯格式

以下方括号内的字段各占1字节。寄存器地址、寄存器数量及16位寄存器值均为
高字节在前、低字节在后；CRC采用Modbus RTU的CRC16，低字节在前、高字节在后。
CRC覆盖从从站地址到最后一个数据字节的内容，不包含CRC字段本身。

#### 1.2.1 读取保持寄存器（功能码 `0x03`）

主站请求（8字节）：

```text
[id] [0x03] [reg_addr_h] [reg_addr_l] [reg_count_h] [reg_count_l] [crc16_l] [crc16_h]
```

- `reg_addr`：起始寄存器地址。
- `reg_count`：连续读取的寄存器数量，单位为寄存器，每个寄存器占2字节。

从站正常应答（`5 + 2 × reg_count` 字节）：

```text
[id] [0x03] [byte_count] [data1_h] [data1_l] ... [dataN_h] [dataN_l] [crc16_l] [crc16_h]
```

- `byte_count = 2 × reg_count`，表示后续寄存器数据的字节数，不包含CRC。
- 寄存器数据按地址递增排列。

#### 1.2.2 写单个寄存器（功能码 `0x06`）

主站请求（8字节）：

```text
[id] [0x06] [reg_addr_h] [reg_addr_l] [reg_value_h] [reg_value_l] [crc16_l] [crc16_h]
```

从站正常应答（8字节，与请求内容相同）：

```text
[id] [0x06] [reg_addr_h] [reg_addr_l] [reg_value_h] [reg_value_l] [crc16_l] [crc16_h]
```

一次写入一个16位寄存器，而非一个字节。当前寄存器表均为只读，
可写寄存器及写入约束待后续补充；以上仅定义正常应答格式。

#### 1.2.3 CRC16计算方法(C)

~~~c
uint16_t proto_local_crc16(const uint8_t *p_data, uint16_t length)
{
    uint16_t crc = 0xFFFFU;
    uint16_t index;
    uint8_t  bit;
    if(NULL == p_data)
    {
        return 0U;
    }
    for(index = 0U; index < length; index++)
    {
        crc ^= p_data[index];
        for(bit = 0U; bit < 8U; bit++)
        {
            crc = 0U != (crc & 1U) ? (crc >> 1U) ^ 0xA001U : crc >> 1U;
        }
    }
    return crc;
}
~~~

### 1.4 当前固件接入（2026-11-03）

UART1（RS485）和UART2（普通串口）均支持本协议，从站地址固定为`0x15`。
沿用现有9600/8N1配置及静默封段机制，一次发送一个完整请求，收到应答后再发下一次。
当前按BSP接收段处理，不拆分一个段内连续拼接的多帧；不将该实现视为完整时序符合性验收。

- `0x03`：可读取`0x0008..0x0015`任意连续子区间；读取全部14项应答33字节。
- `0x06`：当前无可写寄存器，返回异常`0x86 0x02`，不修改参数。
  已保留写回调接口，后续在项目数据适配层定义可写地址、参数范围及实际操作。
- CRC错误、非本机地址、广播地址0、错误长度及带响应异常位的帧不应答；
  当前广播不执行写操作，因为尚无可写寄存器。
- 合法地址和CRC下，未支持的请求功能码返回异常01；读取非法地址或越界返回02；
  读取数量为0或大于125返回03；有效读取区间内测量不可用返回04。
- 异常帧格式：`[0x15] [function | 0x80] [exception_code] [crc16_l] [crc16_h]`。

当前字段映射以一次测量快照为准：

| 地址 | 当前来源／编码 |
| --- | --- |
| 0x08 | 输入电压，mV |
| 0x09 | 用户指定使用Buck输出电流，mA；不是PV输入电流 |
| 0x0A | 电池电压，mV |
| 0x0B | 电池净电流，mA；正充电、负放电，16位补码 |
| 0x0C | 用户指定使用电池电压作为负载电压，mV；不是负载端独立测量 |
| 0x0D | 负载电流，mA |
| 0x0E | 温度，0.1℃；负值为16位补码，无效温度暂填0 |
| 0x0F..0x15 | SOC、充放电功率、日充放电量、充电及保护状态均先填0，待定义来源及编码 |

无符号字段饱和到`0..65535`，电池电流饱和到`-32768..32767 mA`后编码，避免窄化回绕。
无测量快照时返回异常04；已约定但尚无数据来源的字段0只是占位，不表示实际状态正常。
