# 充电状态与模块说明

更新时间：2026-11-04。当前为开发试验版；参数以源码为准。
本文件描述当前实现，已撤回的试验通过Git历史查看。

## 默认流程

1. 默认关闭功率输出，持续采样，256连续有效帧后检查启动/保护条件。
2. 开PWM前保存Vin为Voc估计，输入参考=floor(Voc×0.875)。没有专门开路等待。
3. 初次D=round(Vbat/Vin×1000)+10，受950限制；约20 ms启动
   稳定阶段继续按新帧更新候选，随后选择CV/CC/MPPT。
4. 保护>CV>CC>MPPT，正常运行共用采样/保护/PWM入口。
5. CV确认充满后，有负载继续CV；无负载确认后关PWM进FULL_WAIT。
   新负载或低电压回充条件满足且输入有效时，复用正常启动。

| 状态值 | 含义 |
| --- | --- |
| 0 / 1 / 2 | OFF / WAIT_SAMPLE / START_SETTLE |
| 3 / 4 / 5 / 6 | WAKE_CV / CC / CV / FAULT |
| 7 | FULL_WAIT，充满待机，PWM关闭 |
| 8 | MAINTENANCE，默认停用的保留路径 |
| 9 | MPPT |

无状态10。维护开关SVC_CHARGE_ENABLE_MAINTENANCE默认0，维护代码保留；
充满/负载公共判断仍复用maintenance模块。

## D上下限

单位为千分比，950=95%。1～950为非零接口编码范围，固定15%下限已取消。
正常运行每个有效10 ms帧计算：

```text
输入参考 = floor(启动Voc估计 × 875 / 1000)，本轮保持
D下限 = round(实时Vbat / 启动保存Voc × 1000)
D上限 = 950，取消Vbat/输入参考换算的硬限幅
```

- 下限是理论反向电压平衡点的参考下限，用于降低反向升压风险的试验约束；
  不是反灌检测、电压峰值上限或器件安全保证。主流程、下限校验及CV诊断
  共用启动保存Voc；实时Vin变化不改变下限，电池电压变化仍更新下限。
- 950是最终软件占空比上限，不代表前端功率边界。
  g_charge_input_duty_max_permille保留兼容名称，运行时显示950。
- 原保护优先，随后检查有效区间，再把CC/CV/MPPT当前及候选D限幅。
  下限升高可抬D；MPPT被下限限幅后重建比较基准。
- min==max允许；min>max先停机，FAULT6/DUTY_LIMIT7，置range_conflict。
  连续满足原恢复/启动条件5 s后重新采PWM关闭时的Vin，不要求回到旧参考。
- 启动偏移+10保留；非法编码、无效电压关系或无法实现的下限仍拒绝输出。
- 运行不更新保存的Voc；没有定时停取重测。输入参考仅用于以下CV试验，
  MPPT/CC/启动及可选维护不使用该参考限D。

## CV输入电压约束（首轮试验）

- Vin<输入参考：锁存g_charge_input_limited=1，每个新有效10 ms帧减1‰。
- 已锁存且参考<=Vin<参考+200 mV：保持D，允许CV/软限流提出的减D，禁止加D。
- Vin>=参考+200 mV：清锁存，恢复普通CV；未锁存时不因进入回差区而限制。
- 选择CV和输入约束中较小的候选D，每帧只作一次算法调节，不叠加减两步。
  最低仍到Dmin，触底保持，不因低于输入参考或电池净电流为负而新增停机。
- 仍由Vbat<=14.30 V触发原CV退出，保持D交接CC/MPPT并重新建立MPPT比较基准。
  原14.38 V进入阈值、充满/待机及保护不变，无新主状态。
- 0.875、200 mV及1‰/10 ms为试验参数，不能代表所有前端的能力或稳定性。
  输入参考不是已测最大功率点；外部主动降压/旧Voc的影响仍需验证。

## 模块职责

| 模块 | 职责 |
| --- | --- |
| svc_charge | 状态交接、采样/保护调用、上下限检查及PWM下发 |
| svc_charge_control | 电压比、初始D及输入条件计算 |
| svc_charge_cc / cv / mppt | 算法计算，不直接写PWM |
| svc_charge_protection | 故障判断、确认及恢复条件 |
| svc_charge_maintenance | 充满/负载公共判断及可选维护路径 |
| svc_charge_config | 参数和维护开关 |
| svc_charge_diagnostics | CV观察、误差、Watch兼容标志及故障快照 |

IN_CUR/input_current_ma为Buck总输出，OUT_CUR/output_current_ma为负载；
电池净电流=总输出-负载。没有PV输入电流传感器。MPPT以Vbat×总输出为功率代理。

## 诊断与未解决问题

- CV观察在有效CV帧调D前更新，退出CV保留，init/start/stop清零。
  downward_blocked表示该帧存在向下限幅；不是累计故障。
- 故障快照记录关PWM前状态、D和测量；Watch当前值可能已经是停机后的值。
- 故障3 INPUT_VOLTAGE同时用于输入电压关系无效、D高限低输出200 ms、
  以及低输出加负净电流50 ms。后一旧判断仍在CC/MPPT调用，可能受小电流
  偏差影响；2026-10-30新现象尚待快照定位，未修复。
- DMA BAT_VOL原值>=1760直接关PWM，无上层事件/恢复互锁；业务D可仍非零。
  500 us采样下峰值15.4～15.8 V尚未定位。
- 周期重测Voc、输入不足的即时减载/退出、缓慢启动收敛及硬件验证待办
  集中在.agents/project-memory.md，不在各文档重复维护完整清单。
