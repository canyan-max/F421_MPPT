## 当前自动恢复原则

1. 检测到故障后立即请求关闭PWM。
2. 如果关闭失败，每个服务周期继续尝试关闭，确认关断后才允许恢复。
3. 普通故障的恢复条件必须连续满足5 s；充电过流必须连续满足20 s。
4. 恢复后进入 `WAIT_SAMPLE`，重新检查采样并重新计算初始占空比。
5. 不沿用故障前的占空比。
6. 显式调用 `svc_charge_stop()` 后不得自动重新启动。

## CC、CV与MPPT控制约定

- CC作为Buck公共母线的最大允许电流限制，不代表带负载时的精确电池电流。
- 当前固定4 A仅用于小功率调试，后续最大CC计划设置为9～9.5 A。
- MPPT直接扰动D，以输出功率代理判断方向；达到限流区域由原CC独占D
  调节，释放后重建MPPT基准，两种算法不会在同一个周期同时改D。
- 接管选择和100 mA释放迟滞在svc_charge.calculate_running_duty中，
  MPPT通过pause接口丢弃被打断的比较，reset负责完整复位。MPPT输出仅含
  D及更新/边界标志，不依赖CC结果结构，不处理电流/电压误差诊断。
  已清除旧的动态电流目标变量和getter；当前最大CC直接从配置读取。
- CV作为电池最高电压限制，达到目标电压后优先接管并降低电流。
- 保护层优先级最高，可在任意控制模式下直接关闭PWM。

## 已确认不能采用的判断

- 不能仅用 `Vin <= Vbat` 完整判断输入电源是否消失，因为PWM存在时电池侧可能反向维持或抬高Vin。
- 不能仅因 `Vbat / Vin >= 95%` 或占空比达到950就判定输入掉电。
- 实测故障误判时，`Vin=14.240 V`、`Vbat=13.530 V`，但输入电流仍有2.249 A，说明输入电源仍在供电。
- 上述95%直接故障判断已经撤回。
